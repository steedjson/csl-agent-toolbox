## 2. 技术栈

Django 4.2 / Python 3.12 / PostgreSQL / Redis / Django-Q / DRF 风格视图 / stdkit(私有基础库)。

## 3. 目录结构

```
__PROJECT_NAME__/
├── __CONF_PACKAGE__/          # Django 配置包(settings 分层/urls/wsgi)
├── apps/                      # 业务应用(db 模型基座、base 基础能力、tasks 异步任务)
├── common/                    # 共享工具(视图基类/Service 基类/认证中间件/utils)
├── scripts/                   # 本地质量门禁等脚本
├── docs/                      # 文档中心(见 docs/README.md)
├── data/                      # 初始化数据与业务字典(按需创建)
├── statics/ media/ logs/      # 静态/媒体/日志(不入库)
└── Makefile                   # make check/verify/verify-full 质量门禁
```

## 4. 编码规范

详细分层与编码约定见技能 `csl-django42-project-init` 的 `references/coding-conventions.md`,
核心条款已固化在根 `AGENTS.md`「项目约定」。本文件随项目演进补充项目特有规则。

## 5. 测试规范

- pytest 走 `__CONF_PACKAGE__.settings_test`(sqlite 内存)。
- 纯逻辑测试放各 app `tests/nodb/`;ORM 查询语义测试加 `@pytest.mark.django_db`。
- 新测试一律不连外部数据库服务。
