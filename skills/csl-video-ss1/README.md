# csl-video-ss1 · AI 短视频脚本与分镜提示词生成器

单入口 Skill（SKILL.md 为主体，附校验脚本与证据台账）：输入主题＋参数（分段/秒数/比例/风格/生成方式/语音设定），一次产出完整 AI 短视频套件——脚本、定装照提示词（正/背/侧）、人物锚点清单、按生成方式（1 直出 / 2 首帧 / 3 首尾帧）的分镜提示词、剧名/封面/封底/BGM、生成器投喂指引、产出自检。

核心机制：**锚点清单跨段逐字嵌入**保证人物一致性；**首尾帧一致性契约**（同机位＋不变元素清单）；**细节六维覆盖**取代字数下限；语音口音与提示词语文全部参数化跟随用户输入。

## 使用

装到任意 agent 后，直接说：「做一支 AI 短视频：主题 X；N 段×M 秒；9:16；风格；方式 1/2/3；语音设定：…」。缺参数会一次问齐；「随你」= 方式 3 ＋ 参数自定并声明。

## 边界

适用：15–60 秒、≤6 段、单主角。长片分集、真人实拍、多主角群像会被明确拒绝或警示（见 SKILL.md Boundaries）。

## 验证与证据

- 实测台账：`EVIDENCE.md`（15 次跨 3 模型族冷跑＋真实生成器端到端＋方差分析）
- 产出自检核验器：`python3 scripts/verify_output.py <产出文件> --anchor "锚点块原文" --min 8`
- 实测生成器约束已内置：图生视频首帧需压至约 ≤150KB JPEG，超长提示词会被硬拒而非截断（grok-imagine-video 实测）
