# 配色

## 最小体系

动手前定下三样，之后所有取色从这里出：

1. **底色 + 墨色**：决定基调的两种颜色。先选色调（暖 / 冷 / 中性），白和黑都带一点该色调（纯 `#FFFFFF` 当整页背景、纯 `#000000` 当正文色，都是浪费）。例如暖调：底 `#FAF6EF`、墨 `#2B2118`。
2. **Accent 0–2 个**：优先用品牌或设计系统的颜色；没有品牌约束而需要派生协调色时，用 oklch 保持相同 chroma 和 lightness、只变 hue。
3. **灰阶**：从墨色向底色调和派生（带色调的灰），绝不混用冷暖两套灰；说明文字、边框、分隔线都从这一阶取。

内容 surface（卡片、面板）比页面底色浅一档或深一档，用透明度墨色（如 `rgba(43,33,24,0.08)`）做 hover/选中态与边框，不用彩色边框划分结构。

## 检查

- 每个文字色和它背后底色算对比度：正文 ≥4.5:1，24px 及以上 ≥3:1。做深浅两套 theme 时两边都查。
- 必须区分的元素（图表类别、状态色）在 lightness 上拉开差距，不能只靠 hue；蓝/橙配对优于红/绿（色盲安全）。
- 图表与信息图类别色 ≤ 6 个，超过就分组或用 lightness 分档。

## 占位与禁忌

- 图片没到位用带标签的灰色 placeholder 块（`[图：产品照]`），不留破图。
- 大片渐变铺底、紫蓝渐变、每块卡片一个新颜色：都是 AI 套路，不用。
- 为特定品牌工作时，从用户给的品牌资产里抄**确切的值**（hex 照抄），不从记忆里猜品牌色。
