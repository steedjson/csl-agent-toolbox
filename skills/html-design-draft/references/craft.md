# 设计纪律（全文）

SKILL.md 里是简短规则；这里是理由与细节。用户对某个设计决定有异议时读它。

## 内容

- **不放凑数内容。** 绝不为了填满空间加 placeholder 文字、假区块、装饰性数字或图标。某个区块显得空，是要用 layout 和构图解决的设计问题，不是靠编内容。少即是多。
- **加材料前先问。** 觉得再加一个区块、一段 copy 会更好时，先问用户；他们比你了解受众。
- **定点修改只改那一处。** 小的定点请求只改被点名的元素，其余一切原封不动。做完被要求的，再**建议**其余，不未经要求动手。
- **沿用已有视觉语汇。** 在已有设计上添加内容，先读懂它：copy 口吻、配色、hover 态、阴影与卡片 pattern、密度，照着来。
- **缺的真实信息用显眼占位**（`[待填：价格]`），绝不编造价格、日期、人名、数字。
- **绝不用 lorem ipsum**，绝不写「欢迎访问我们的网站」这类放哪家都成立的套话。

## 审美

- 没有品牌约束时，动手前先定一个**大胆且叫得出名字**的方向：极致极简、editorial/杂志、brutalist、art deco/几何、柔和粉彩、工业实用、奢华精致、复古未来……拿这些找灵感，但作品要忠于选定方向。大胆极繁和精致极简都行，关键是**有意为之**。问自己：这个设计让人记住的是哪一点？
- **避开 AI 套路**：大片渐变铺底、emoji、左边框 accent 卡片、被用滥的默认字体（Inter、Roboto、Arial、Fraunces 当首选）。emoji 只有品牌本身在用时才用。
- 反着来才有辨识度：意料之外的 layout、不对称、重叠、斜向流、打破 grid 的单个元素、大片留白**或者**有控制的密集；背景用质感（噪点、几何图案、层叠透明、戏剧化阴影）而不是默认纯色。
- 多轮生成之间不要收敛到同样的选择：换 theme、换字体搭配、换审美方向。

## 备选与 variation

- 方向未定时，给 2–4 个**真正不同**的候选，每个探索一条说得出名字的维度（「暖调 editorial」对「密集数据优先」）。做决定所需的保真度不等于交付保真度：低保真草图足以选定方向。
- 每个备选在你的回复里（不是画板上）给如实的动机与主要取舍；一组备选只有你偏爱的那个有人替它说话，那是做过手脚的投票。
- 备选命名保持稳定：一块画板叫了「方案 B」，就一直是这个身份，绝不在轮次间改名换号。
- 方向定了以后用户要可留用的 variation 时，至少给 3 个：既有照章办事的，也有新颖交互、layout、隐喻的，让用户能自由搭配，而不是供一个「完美选项」。

## Layout 与 scale

- 成组兄弟元素一律 flex/grid + `gap`；这样排布经得起直接编辑（拖动、删除、复制），空白文本节点经不起。
- 现代 CSS 是帮手：`text-wrap: pretty`、`aspect-ratio`、`clamp()`、subgrid 都可用。
- 触控目标 ≥44px（mockup 里的也照样）；印刷正文 ≥12pt；字号按实际观看距离定，不按惯例。

## 无障碍（画出来就无障碍）

- 控件用真元素：`<button>`、`<a href>`、`<input>`+`<label>`。带 role 的 div 看起来一样，Tab 键会跳过、读屏没东西可读。
- 只有图标的按钮加 `aria-label`；装饰性 SVG 加 `aria-hidden="true"`，表意 SVG 加 `role="img"` + `aria-label`。
- 文字对比 ≥4.5:1（24px 起 3:1），每个 theme 下都查：说明文字的灰、白字压彩色填充最常不达标。
- 必须区分的颜色在 lightness 上拉开，不能只靠 hue；蓝/橙优于红/绿。

## 落地页与营销稿

按营销结构搭：一个 hero（一句话说清提供什么 + 单一 call to action）；可信度证明（评价、客户 logo、数字——取自用户材料或显眼占位）；回答访客真实疑虑的利益点区块，不是功能罗列。每页一个主行动，向下重复出现，不是三个按钮互相争抢。copy 就是产品：写得具体，扎根用户告诉你的东西。

## 示意图与信息图

- 先在纸上或脑中排好节点与流向，再写代码；正交布局（横向流程或纵向层级），不斜排。
- 节点统一：同层同级同尺寸、同圆角、同描边；箭头方向全局一致，箭头语义（触发/包含/数据流）不超过 3 种。
- 配色 ≤3（底、节点、强调），强调只给关键路径；文字放进节点前先量：放不下就减字或放大节点，绝不溢出。
- 图例放在第一眼能看到的地方；数字信息图每个数字配一行说明，数字用 `font-variant-numeric: tabular-nums`。

## 印刷品

海报、传单、备忘录、报告等要交 PDF 的：A4 用 794×1123（96dpi）或 2480×3508（300dpi）；留出边距与出血；正文 ≥12pt；交付前确认字体已加载（Google Fonts 的字体打印/导出 PDF 时才嵌入，离线打开会回退 fallback）。

## 手机与设备 mockup

不画假 chrome：不画假状态栏（「9:41 · 电池」）、假键盘、假浏览器工具栏。真机上真的会叠在上面，画上去的假货显得幼稚。那块空间留白。

## 复刻

有源码就从源码复刻：读组件与样式，把页面实际用的 asset 复制过来，确切的数值照抄，不四舍五入、不吸附 4/8px 网格、不凭训练记忆。截图只当高层参考。读不到源码就说明并停下。他人受版权保护、有辨识度的 UI pattern 或品牌视觉元素不复刻，除非用户显然属于该公司；转而做尊重知识产权的原创设计。
