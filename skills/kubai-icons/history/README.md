# 早期产物

这套图标在定型之前的三个版本，按时间顺序排列，保留下来作为过程记录。三个页面都是独立的单文件，用浏览器直接打开即可。它们用的是当时的规则，和现在的 `src/`、`PROMPT.md` 不完全一致。

- `01-board.html`：灰色画板版。最早从文件夹图标衍生出的 10 个功能图标，加上文件夹本身；每列一个图标，下面是 32、24、20px 的实际尺寸，以及八种主色和两种 Mono。
- `02-twelve.html`：为 X 帖子做的 12 宫格。4×3 的圆角方块，可以切换色板、一键演示。之后的大部分规则都是在这一版上反复调整出来的：外描边、前后片、白色和深色标记、Z 轴关系、厚度带。
- `03-system.html`：20 个图标的大画布，附上第一版生成提示词。每格带 24px 对照，画布底部是 20 个图标在 24px 下的一排。
