# 派收登记行（复制用）

用法：每派出一件需要回收的活，复制一行到当天的派收／接力记录。**只追加，不改、不删已写的行**：状态变了就在下面追加一行新状态，开头写同一个「任务标识」，原来那行的字段（尤其原预计交时、结果放哪）原样留着。

状态一共五个，别混用：

| 状态 | 意思 | 还在未完清单里吗 |
|---|---|---|
| `待收` | 活已派出（或开跑），还没人确认接下 | 在 |
| `已接单` | 执行人确认接下这件活，**成果还没到** | 在 |
| `已收到成果` | 交付物已到约定位置，收的人看见了，**还没核** | 在（待核） |
| `已验收` | 按 evidence-before-done 技能核过，可交下一棒或关闭 | **不在了** |
| `已取消` | 有权拍板的人明确说不做了 | **不在了** |

另有三种追加行：`续期`、`升级`、`退回`。它们只记过程，**不让任务退出未完清单**。

注意：
- **等待结束 ≠ 成果回来**。后台命令停了、对方说「好了」，都要去结果该在的地方看；看到了才写 `已收到成果`，没看到仍是未完。
- **到点查所有未完项**：不只查没人接的；已接单到点没交、已收到成果还没核、退回等重交的，都按各自状态去查（对应节点见 `../SKILL.md` 第 3 节）。查的时间点可以是预计交时＋约 5 分钟，这只是示例，按任务时限调整。
- **到点谁查要写具体的人**：他可能不在线，就写授权接替人，或他下次能查的时间。实际查晚了照实记，不写「已兜住」。
- **新预计 ≠ 正式改期**：写 `续期` 行，原承诺、原因、影响都留着；执行人报的新时间只是新预计，有权的人（一般是总控，在已有权限内）确认后，追加一行写明谁确认，才算正式改期。确认前仍按原承诺算逾期。
- 核对技能 evidence-before-done 的位置：`../../evidence-before-done/`（相对本文件）。

## 待收（开跑当下写）

```
待收｜任务标识：________｜什么活：________｜谁在干：________｜谁来收：________｜预计交时：____-__-__ __:__｜到点谁查：________｜若不在线：授权接替人________／下次可查时间__:__｜结果放哪：________｜做到什么算完：________｜建议下一棒技能：（可空）
```

## 已接单（执行人确认接下；成果还没到）

```
已接单｜任务标识：________｜几点：__:__｜谁接的：________｜预计交时：（不变则写「同原行」）
```

## 已收到成果（交付物到了约定位置；还没核）

```
已收到成果｜任务标识：________｜几点：__:__｜结果在哪：________｜是不是约定位置：是／否｜待核
```

## 已验收（核过；退出未完清单）

```
已验收｜任务标识：________｜几点：__:__｜谁核的：________｜怎么核的（一句话）：________｜交给谁／关闭：________
```

## 退回（核了没过；仍在未完清单）

```
退回｜任务标识：________｜几点：__:__｜缺什么／错在哪：________｜已告知执行人：是／否｜新预计（执行估计）：__:__｜正式改期：未确认／已由____确认
```

## 已取消（有权的人拍板不做；退出未完清单）

```
已取消｜任务标识：________｜几点：__:__｜谁拍板：________｜原因一句话：________
```

## 到点未完（续期；不覆盖原承诺）

```
续期｜任务标识：________｜原承诺：__:__（保留）｜新预计（执行估计／建议）：__:__｜正式改期：未确认／已由____确认｜原因一句话：________｜影响：________｜仍由谁收：________
```

有权的人确认后，再追加一行同格式的 `续期`，把「正式改期」写成「已由____确认」；原承诺那一格照旧保留。

## 过点升级（没人接、到点没交、交了没核，追不上时）

```
升级｜任务标识：________｜原行摘要：________｜当前状态：________｜实际几点查的：__:__｜过点时长：__｜谁在追：________｜下一步：________
```

## 放行后叫开工（授权／放行一出当场写）

```
叫开工｜任务标识：________｜放行／授权摘要：（不写密钥）｜执行人：________｜交付物：________｜交时：________｜对方回执：已接单（几点）／开工证据在________／尚未回
```

## 开工／收工点名（扫自己派出的、还没「已验收」或「已取消」的活）

扫这些状态：`待收`、`已接单`、`已收到成果`（待核），以及最后一行是 `续期`、`升级`、`退回` 的任务。

```
点名完｜剩 N 件｜最早到点：__:__｜过点未接单：N｜已接单到点未交：N｜成果到了未核：N｜退回待重交：N｜新预计未确认：N｜需报新时间：N
```
