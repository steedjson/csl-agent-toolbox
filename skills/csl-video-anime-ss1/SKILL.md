# 动漫短视频脚本与分镜提示词生成器

一次交付可复制到生成器的完整文本套件：参数、剧本、角色设定图提示词、角色与画风双锚点、分镜、包装、配乐、投喂指引和自检。

核心问题是跨镜头角色变形、画风漂移和动作断裂。用逐字重复的双锚点固定设计，用可执行的动作阶段控制动画连续性。默认采用 2D 赛璐璐；按题材选择具体视觉设计，避免仅堆叠“动漫、精美、高画质”。

## 边界

- 本技能正文及默认产出全部使用简体中文，包括对白、旁白、画面提示词、维度名称与自检。繁体输入也默认转为简体产出；只有用户明确要求其他语言时才切换，并声明采用语言。不照搬原技能“跟随输入字形”的规则。
- 默认只生成文本方案。用户明确要求实际生成图片或视频时，先检查可用工具的输入字段、时长和参考图能力，再按投喂指引执行；缺少工具就交付文本并说明未出片，不编造结果。
- 适用：15–60 秒、最多 6 段、1 位主要角色。需要长片或分集时建议先拆集；多主角群像应改用逐角色设定和独立连续性管理，不能声称本技能保障全部角色一致。
- 副角可给简短设定，明确“一致性弱保障”；不要用副角承担跨段关键动作。
- 一致性约束用于减少漂移，不保证生成器必然遵从。文本自检通过不等于出片质量通过。

## 工作流程

按以下七步交付完整文本套件。

## 1. 接收主题与参数

先读取已有主题、脚本及参数，不重复询问已给信息。缺少必填项时一次问齐：

| 参数 | 规则 |
|---|---|
| 主题或现有脚本 | 必填；改编时保留原故事与用户要求的对白，不擅自改剧情 |
| 分段数 × 每段秒数 | 必填；总长 15–60 秒且不超过 6 段 |
| 比例 | 必填，如 9:16 或 16:9 |
| 生成方式 | 必填：1 直出／2 首帧／3 首尾帧 |
| 语音 | 必填：普通话等口音、可选音色与语速，或“无语音”；无旁白与无语音分别处理 |
| 动漫画风 | 可选；默认 2D 赛璐璐，允许水彩手绘、国风二维、三维卡通等明确方向 |

用户说“随你／随意／按默认”时，补齐其余缺项：默认 3 段 × 5 秒、9:16、方式 3、2D 赛璐璐、普通话且音色适配角色。仍缺主题才询问主题。开头始终声明全部最终参数及总长。

## 2. 建立角色与画风双锚点

先根据故事选择视觉方向；除非用户要求比较，不输出整套风格目录供选择。

**角色锚点块**：5–8 项固定设计，至少含年龄与体型、脸形与眼睛、发型与发色、服装轮廓与配色、标志配饰。用明确形状、位置或色号，避免“漂亮、酷”等不可核对词。服装层次、配饰左右位置在转身时保持一致；正背侧图只呈现该视角可见特征，不强行把背面的脸或被遮挡配饰画出来。

**画风锚点块**：至少固定线稿粗细与颜色、人体与五官比例、主色板、上色或明暗规则、背景绘制方法。2D 赛璐璐写清硬边阴影层数、阴影色偏向和高光方式；水彩等风格改用符合媒介的边缘、透明度与晕染规则，不同时要求硬边赛璐璐。三维卡通固定模型比例、材质和渲染方式，不强加二维线稿。

**双锚点相容性（冻结前硬性检查）**：把角色要求与画风限制逐项对照，至少核对高光位置、阴影层数、线条与细节、比例和色板。遇到“仅／只／禁止”等限制，检查是否排除了角色必需特征。不能只验证两块被复制了多少次。

例如角色要求眼睛高光，画风却规定高光仅限头发与金属，这是冲突。若保留眼睛高光，须在画风允许范围中明确包含眼部；若用户明确要求眼部无高光，则统一修改角色设计。不能把同一高光换名为反光来绕过限制，也不能靠块外注释或一句“无冲突”掩盖。用户明确指定的设计优先保留；两项明确要求无法同时成立时先询问取舍，不自行删除。自拟设计则直接统一规则，无需追问。

**光照术语与限制范围（硬性）**：出现高光、辉光或受光要求时，按实际画面现象区分，不靠换词解套：

- 镜面高光：材质表面的局部反射亮斑，如眼球亮点、金属闪点；可以画成硬边色块，位置和强度受光源、表面朝向与视角影响。画风允许清单须包括角色必需的部位。
- 光源辉光：发光物自身及其周边的光晕，例如信封开口发亮。不是脸或手套表面的亮边，也不自动授权任何表面发亮。
- 表面受光：光源照到脸颊、手背或衣物产生的受光面／轮廓亮边；须写明光源、受光部位与明暗形状。赛璐璐可用硬边浅色块表现，不能因为颜色白、面积小或边缘亮就一概当作镜面高光。

画风块内分别写明三类现象的允许或禁止范围。若禁止皮肤镜面高光而保留脸颊受光，须明确“禁止皮肤镜面反射亮斑；允许指定光源照亮指定皮肤部位”，不能写含混的“禁止皮肤高光”再在别处要求脸部辉光。辉光条只管理发光体及光晕；表面亮边写入受光条。只要设计包含可关闭、遮挡或缺席的发光体，必须在冻结画风块中分别写明：光源关闭或从场景移除时，其辉光及其造成的受光消失，其他光源照明与角色固有色保留。光源在镜头外或被物体挡住镜头视线，不等于停止照明；不透过遮挡物画出发光体，光晕只呈现实际可见部分，仍有光路到达的可见表面保留该光源受光。光源到某一受光面的直达光路被完全阻断时，仅该面的直达受光消失，不自动删除光源辉光或其他面的受光；部分阻断按剩余光路处理，不一概全灭。无明确设计时不凭空补反弹光。不能仅在单个场景、自检或块外解释。

同一亮斑、来源与位置都未变而仅改名，仍属绕过限制，必须修改冲突规则原文；有光源和现象依据的正确分类才是合法区分。用户只说“高光”且范围不明时，先结合上下文明确采用的含义并声明，涉及两条不可修改的相反要求才询问取舍。

相容后才冻结两块。修正任一块时重查另一块，并替换已生成的全部提示词副本后逐份复核。交付自检给出“角色要求 → 画风允许范围 → 一致性结论”的具体证据，而非只列通过。

两块先分别列出，随后在每份正／背／侧设定图、首帧、尾帧、视频、封面及封底提示词中逐字复制，禁止省略、改写或用“同上”代替。块内不得插入纠正注释；视角、遮挡、表情、动作、机位和光线变化写在块外。超过 4 段时，每完成 2 段重申两块原文；重申不代替各提示词中的完整块。

锚点只记录整片固定设计，避免把可移动道具或动作写死。手持信件、剑等另列状态表，记录持有者、左右手、位置和变化来源。光照可以改变表面观感，不能改变设计固有色。

## 3. 脚本与角色设定图

- 列逐段时间区间、事件、情绪、起止姿态及道具状态。每段一个主要动作，副动作服务主动作；避免数秒内连续跑跳、变身、换景再对白。
- 提供正、背、侧面各一份角色设定图提示词：相同比例与中性光线、全身无遮挡、背景简洁，不烧录文字；包含双锚点、角色姿态、虚拟镜头或投影、布料与发束的绘制方式。
- 动漫材质写成可画出的色块、轮廓、反光与褶皱；避免默认加入写实毛孔、照片级皮肤、实拍景深或无理由的“8K”词串。

## 4. 按生成方式输出分镜

每份提示词都必须独立可投喂。正文覆盖六个维度：主体与双锚点／场景前中后景／虚拟镜头、机位与构图／光线方向与色彩／绘制材质与动作细节／具体画面质量约束。质量约束如稳定线宽、无多余肢体、无闪烁，不靠分辨率形容词凑齐。

- **方式 1**：每段 1 份视频提示词，含完整场景、起止状态、动作时间轴、运镜、声音。
- **方式 2**：每段 1 份首帧图片提示词 + 1 份视频提示词。图片只描述可见静态构图；视频解释从首帧开始如何动作。
- **方式 3**：每段先列不变元素清单，再提供首帧、尾帧图片提示词及视频提示词，共 3 份。首尾图固定同机位、同虚拟焦段或同正交投影、同构图框架，视频相应使用固定镜头；需要换机位则安排到下一段。清单固定场景骨架、背景物、固定道具、双锚点及动作轴线；分别写出允许变化的人物姿态、可移动道具和光线。尾帧新状态须由视频中的动作产生，不能无来源增添元素。

每段附明确“对话”和“旁白”，标出时间与说话者，并原样引用最终语音参数。对白长度须留出停顿和动作时间，避免说完需要超出片长；无法容纳时缩句或另段安排。要求无旁白则写“旁白：无”；无语音则“对话：无；旁白：无”，保留指定的环境音与音效。不要擅加解说。

### 动漫动作连续性（硬性）

- 将主动作分成可理解的阶段，例如“预备 → 发力 → 接触／停顿 → 缓冲收势”；按每段时长分配，不强制每个镜头都做夸张预备动作。
- 固定动作轴线、角色朝向和屏幕运动方向。连续动作的上一段尾态与下一段首态保持姿态、持物手、视线及场景空间一致；转场或时间跳跃须明确交代。
- 脚掌接地，抓握有接触，衣摆发束有延迟与收势；避免肢体数量变化、道具瞬移、服装图案漂移、发色闪烁和背景线条游动。
- 有限动画可采用姿势保持、眨眼、口型和分层视差；不要将所有部位持续晃动当作动画感。
- 速度线、冲击帧、拖影、夸张形变只在对应动作节拍局部启用，随后回到既定比例与线条；不能把整段变成随机变形。
- 可写帧率或“二拍一”作为创作目标，生成器没有对应控制字段时明确属于提示意图，不能声称得到逐帧控制。

## 5. 包装与配乐

提供 3–5 个剧名、封面与封底各 1 份提示词。两份都包含完整双锚点、比例、六维度和标题留白，不默认要求生成器准确绘制中文文字；剧名后期排版。

配乐先写方案，再按场景决定是否调用 `csl-ace-step-music` 出音频。总时长等于分段数 × 每段秒数；对白处压低音乐，并写明收尾。

- **有对白或旁白**：生成 1 首无人声 BGM，时长等于全片，不逐段拆。
- **无语音**：生成 1 首 30 秒主题曲，按剧情自动写 4–8 句简体歌词；另生成 1 首全片时长的无人声 BGM。
- **用户要求纯环境音**：不调用音乐技能，只给相同总长的环境音方案。

自动选择：风格从流行、古风、史诗管弦、电子、氛围中选；情绪按剧情；乐器默认钢琴、弦乐，热血或动作段加鼓和电吉他。人声用女声清亮有力、普通话。格式 mp3、128k、48000，BPM、拍号、调式不填。调用前逐条写明选择。音频存入项目 `video/`，核对可解码且时长误差不超过 1 秒；失败不推翻已完成的分镜。ACE-Step 只有 turbo 时不做提取、叠轨、补全。

## 6. 投喂指引

1. 先生成角色设定图，人工确认轮廓、配色和配饰位置。工具支持参考图时复用同一份角色参考，工具支持种子时可固定种子；文本相同不构成一致性的保证。
2. 方式 1 直接投喂视频提示词；方式 2 先生成首帧再图生视频；方式 3 先生成首帧，并优先用首帧作参考生成尾帧，再走真正支持两张边界帧的接口。
3. 仅支持首帧的接口，明确告知由方式 3 降为方式 2；尾帧作为目标参考和验收依据，不能声称尾图参与了生成。参数声明与自检也须同步记录实际使用方式。
4. 无语音能力时，提供带时间轴的字幕或后期 TTS 方案；无指定语言支持时先说明约束，取得用户明确选择后再换语言，不能静默翻译。
5. 请求体与图片大小按当前接口限制处理，过长时优先保留双锚点、动作、运镜，再压缩场景修饰。不要把某一生成器的大小限制写成所有工具的固定上限。
6. 实际生成时按下方固定目录归档，按段命名并以路径交付。元数据用 ffprobe 等工具核对；视觉核验可抽取每段 3–5 帧，缩成小型 contact sheet 查看角色、画风、道具与接续。未核对的口型、逐帧运动与声音明确留待实测。

### 项目产物目录（硬性）

每支影片建立独立项目目录，默认 `~/Downloads/csl-video-projects/<项目名>/`，用户指定路径时以其为准。固定使用以下四个子目录，产物不要散放在项目根目录，也不要写进技能源码目录：

```text
<项目名>/
├── frames/    # 角色设定图、首尾帧、参考图、压缩后的生成器输入图
├── qa/        # 抽帧检查图、ffprobe、哈希清单、冷跑报告、出片记录
├── script/    # 原始脚本、完整生成方案、提示词及其结构化副本
└── video/     # 分段视频、重试视频、最终成片、配乐与导出音轨
```

失败和弃用产物保留原文件名，并在 `qa/` 记录弃用原因；重试用新文件名，不覆盖原始结果。交付链接、证据台账与哈希清单必须引用整理后的真实路径。执行中有异步任务时等其完成再移动对应文件，避免输出落回旧位置。

## 质量标准

### 7. 交付前自检（硬性）

逐项输出“通过／不通过＋证据”。不通过先修改产出原文再复核，不能仅提示用户自行修正。

1. 参数完整、时间区间无重叠，总长符合范围。
2. 双锚点在每份独立提示词内逐字存在，不能只统计全文总次数；设定图、分镜、封面和封底均检查。
3. 方式 1／2／3 每段分别 1／2／3 份提示词；方式 3 有不变元素清单且首尾同机位。
4. 每份提示词覆盖六维度，图片提示词不塞入多时刻动作；画面描述与锚点无冲突，角色块与画风块也相容。逐项给出角色要求与画风允许范围的对照，特别检查眼部高光是否被排除；光照要求给出“光源 → 画面现象与部位 → 镜面高光／光源辉光／表面受光归类 → 对应允许范围”的证据，禁止只改名称消除冲突。有可关闭、遮挡或缺席的发光体时，从冻结画风块原文摘录关光、镜头视线遮挡和光源到受光面光路阻断各自的辉光、受光、其他光源照明和固有色规则，明确被挡的是哪条路径，并核对每份提示词所含画风块与原文一致；仅场景中有说明不算通过。发现遗漏或冲突须修改锚点原文及全部副本再逐份重验。
5. 动作有起止、接触和收势；逐个相邻段从实际分镜原文摘录“上一段末态 → 下一段首态”，对照姿态、朝向、视线、左右手、道具相对身体的位置与光源状态，并逐项给出一致或差异及证据。方式 2／3 对照下一段首帧，方式 1 对照下一段视频起态；同一段视频起态也须与其首帧一致。不能以脚本概述或“接上段”替代原文核对。发现无交代的位移或其他差异，先修改对应分镜原文及受影响的脚本、状态表和自检，再逐项重查；确需转场或时间跳跃时明确说明变化来源。检查轴线和无来源的新元素。
6. 每段对话、旁白与最终语音参数一致；字幕／TTS 降级有说明。
7. 有对白时全片 BGM 为 1 首无人声 mp3；无语音时另有 1 首 30 秒主题曲；纯环境音时确认没有调用音乐生成。时长误差不超过 1 秒。
8. 默认全文简体；明确指定其他语言时与参数声明一致。
